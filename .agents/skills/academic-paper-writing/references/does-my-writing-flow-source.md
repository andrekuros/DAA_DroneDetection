# Does My Writing Flow? (Source Check)

Quick test for paragraph clarity and section flow.

## External-reader test (per paragraph)

1. Does this paragraph have **one** explicit message?
2. Does the **first sentence** state what this paragraph will do?
3. Are all key nouns/terms readable without hidden context?
4. Does each sentence connect to the previous one with a clear relation
   (cause, contrast, consequence, refinement, example)?

## Reverse outlining (per section)

1. Write down the thesis / main claim of the section.
2. Write down each paragraph’s topic sentence.
3. Under each topic sentence, list evidence / explanation points.
4. Check mapping: topic sentence → thesis; evidence → topic sentence.
5. Revise or remove any paragraph that cannot be mapped cleanly.

## If flow is still weak

1. Add temporary section headers during revision.
2. Add explicit transition phrases (however, therefore, in contrast, specifically).
3. Remove unnecessary headers before finalizing.

## Revision heuristic

Prefer splitting a overloaded paragraph over adding vague connective tissue.
If two messages compete, make two paragraphs.
