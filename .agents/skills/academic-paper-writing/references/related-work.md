# Related Work

## Goal

Position the paper by theme; every cluster ends with a contrast to this work.

## Paragraph skeleton (per theme)

1. One-sentence theme
2. 2–4 citations with *what they did*
3. Gap sentence: “Unlike …, we …”

## Typical clusters (multi-robot / learning)

- Classical assignment / market-based allocation
- Learning and MARL for task allocation
- Hybrid learning + combinatorial solvers
- Partial observability / communication / time windows

## Avoid

Citation dumps; “recent work uses attention” without refs; criticizing strawmen; claiming uniqueness without a gap sentence.
